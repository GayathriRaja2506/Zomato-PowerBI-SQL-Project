Zomato Restaurant Ratings & Orders Analysis

Project Overview
This project analyzes Zomato restaurant ratings, customer behaviour, order trends, delivery performance, and order status using MySQL and Power BI.

Tools Used
- MySQL
- Power BI Desktop
- Power Query
- DAX

Project Structure
- `SQL/` – SQL scripts for data cleaning and analysis
- `Dataset/` – Original and cleaned datasets
- `PowerBI/` – Power BI dashboard file
- `Screenshots/` – Dashboard screenshots

Key Analysis
- Total orders and total order value
- Delivered and cancelled orders
- Average order value and delivery time
- Restaurant ratings and reviews
- Customer segmentation and behaviour
- City-wise and monthly order trends
- Top restaurants by revenue

Project Objective
To use SQL for data preparation and analysis and Power BI to create interactive dashboards that help understand restaurant performance, customer behaviour, and order trends.

Author
